# Headless example

This directory demonstrates the Agent-neutral artifact boundary. The sample copper material and effect are ordinary JSON manifests; they could have been written by a human, generated by an external Agent, or compiled from DCC output.

Run:

```bash
npm run build:cli
node dist-cli/cli/melo.js variant compile \
  --master examples/headless/master.demo.json \
  --recipe examples/headless/variant.copper.demo.json \
  --assets examples/headless/assets \
  --renderer fixed-camera-cinematic \
  --require-hashes \
  --out /tmp/copper-plan.json
node dist-cli/cli/melo.js quality check --plan /tmp/copper-plan.json --strict --require-hashes
```
